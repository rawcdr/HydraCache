# Raw Data

This directory is intended for raw data ingestion.

**Expected input:**
- SEC EDGAR 10-K PDF filings.

**Naming convention:**
- `[TICKER]_[YEAR]_10K.pdf` (e.g., `AAPL_2023_10K.pdf`)

## Initial Phase 1 Corpus
For the initial implementation and testing, please place exactly **one** 10-K filing in this directory. 
Later phases will expand to support multiple filings.

*Note: Data ingestion logic is planned for Phase 1.*
